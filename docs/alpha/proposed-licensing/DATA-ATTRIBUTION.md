# Dataset attribution, separate from software licensing

No acquired dataset is included in the proposed source handoff. Request examples
and locators do not change the provider's terms. Preserve source IDs, timestamps,
provider/collection license links and the acquisition manifest with scientific work.

Sentinel-2 example: the selected observations are from 2025. For redistributed
modified subsets use `Contains modified Copernicus Sentinel data 2025`, with the
[Copernicus legal notice](https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice).
Verify the applicable provider/item terms for each dataset before redistribution.
This attribution is separate from any Element 84/AWS service acknowledgment.

WeatherBench2 ERA5: identify the exact 64×32 regridded product, source store and
times, and acknowledge ERA5/ECMWF/Copernicus and the WeatherBench2 data preparation.
Follow the [WeatherBench2 data guidance](https://weatherbench2.readthedocs.io/en/latest/data-guide.html)
and the source's ERA5 data terms/citation requirements. A software license does not
license the ECMWF dataset; no universal data license is asserted here.

IMERG is not part of the two-task human trial. If used, follow
[NASA POWER acknowledgment and citation guidance](https://power.larc.nasa.gov/docs/referencing/)
and the upstream IMERG product requirements. Do not present liquid precipitation
probability (%) as a precipitation amount (mm/day).

Provider citations and acknowledgments that are recommended rather than mandated
should still accompany publications for scientific traceability; that recommendation
is not a new software-license condition.

# Next observation-model decision gate

Recommend **one ATL06 release-007 granule, one beam and a bounded along-track segment interval** as the first non-raster target. This is a documentation and code-capability investigation, not specimen qualification or an implementation. Physical chunk/index/filter details, actual fill values, version identity and archive redirect policy must be inspected on the chosen original granule before admission.

| Product | Scientific identity and native organization | Minimum model obligation |
| --- | --- | --- |
| ATL06 v007 | Beam groups `gt1l` through `gt3r`; `land_ice_segments` contains aligned but sparse along-track observations. Preserve `segment_id`, Float64 latitude/longitude and `delta_time`, land-ice height `h_li`, uncertainty and `atl06_quality_summary`. Segments have spatial support along the track, not raster-cell area. | Separate beam tables with source indices and IDs, source fill, AOI membership and explicit quality policy. Preserve GPS epoch metadata; conversion to UTC requires an explicit time policy. Do not synthesize missing segments or regularize the track. |
| ATL08 v007 | Beam `land_segments` with terrain and canopy subgroups; 100 m land observations coexist with finer subsegments and photon-linked information. Terrain elevation and relative canopy height are different variables. | Preserve parent/subsegment dimensions and segment relationships. Declare selected metric, support and quality fields. No automatic canopy/terrain substitution or cross-beam merge. |
| GEDI L2A | Per-beam shot observations with shot geolocation, elevation, quality/degradation/sensitivity and an `rh` percentile dimension. `shot_number` requires exact UInt64 identity. | Shot table plus a named percentile dimension; keep the selected algorithm and geolocation variant. No rasterizing shots, floating-point IDs or implicit quality threshold. Inspect the actual release's units: older dictionaries contain known discrepancies. |

The official [ATL06 v007 dictionary](https://nsidc.org/sites/default/files/documents/technical-reference/icesat2_atl06_data_dict_v007.pdf), [ATL06 ATBD](https://nsidc.org/sites/default/files/documents/technical-reference/icesat2_atl06_atbd_v007.pdf), [ATL08 v007 dictionary](https://nsidc.org/sites/default/files/documents/technical-reference/icesat2_atl08_data_dict_v007.pdf), [NASA ATL08 tutorial](https://ornldaac.github.io/cms/tutorials/icesat2.html) and [GEDI L2A dictionary](https://edcftp.cr.usgs.gov/project/lpdaac/GEDI_L2/gedi_l2a_product_data_dictionary.html) establish these distinct organizations. They do not establish the physical layout of an unseen source. Version and units must come from the admitted original object and its matching guide.

The conditional byte-range transport, pinned source identities, bounded metadata reads, restricted HDF5 decompression, cancellation, consumer backpressure and final-validation transaction can be reused. Rank-one coordinate reading is evidence that some low-level HDF5 mechanisms exist; it does not authorize rank-one scientific observations through `ArrayInspection`, which currently requires rank-two numeric science and `ArraySlice` axes.

The missing shared capabilities are an observation batch with exact integer IDs and source indices; aligned columns of Float64/Float32/integer types; independent beam lengths; a bounded index-range or index-run selection; direct geolocation membership; separate source/quality/AOI masks; an explicit epoch/time representation; and transactional table or trajectory output. Extend the streaming contract deliberately rather than manufacturing an `x`/`y` grid. Zarr can store these columns, but the current raster writer and its row/column assumptions must not be reused as the public observation model. A table export format can be chosen at that next gate.

For the first ATL06 slice, inspect six aligned columns plus uncertainty and epoch metadata, qualify actual chunk/filter/index layouts and missingness with h5py, and compare a small beam interval and geographic mask independently. Keep other beams, ATL08 hierarchy and GEDI percentile/algorithm dimensions outside that first implementation. No ATL06, ATL08 or GEDI runtime support was added in Wave 4.
